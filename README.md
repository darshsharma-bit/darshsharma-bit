# Engineering Approach

```text
PROBLEM
   │
   ▼
UNDERSTAND
   │
   ├── requirements
   ├── constraints
   └── failure cases
   │
   ▼
DESIGN
   │
   ├── architecture
   ├── interfaces
   └── execution flow
   │
   ▼
BUILD
   │
   ├── implementation
   ├── integration
   └── validation
   │
   ▼
MEASURE
   │
   ├── correctness
   ├── performance
   └── usability
   │
   ▼
ITERATE
```

I aim to move projects from **idea → architecture → implementation → verification**, rather than stopping at a prototype.
